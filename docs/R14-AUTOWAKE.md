# R14：自动唤醒改成网格模型（2026-11-18）

## 规则

- 网格大小固定选项：`10 / 20 / 30 / 40 / 60 min`，边界对齐本地 `00:00`；50 不整除 24h，不提供。
- 采样间隔：`30s` 或 `60s`。每格点数 `n = gridMinutes × 60 / sampleSeconds`。
- 网格分类：只要沾到热区就是 `hot`，否则沾到冷区就是 `cold`，否则 `normal`；`hot > cold > normal`，不看重叠时长。
- 三类分别配置**每格期望**：`normalExpected / lowExpected / highExpected`。
- 每个网格进入时：
  1. 生成 `n` 个正态权重（中心在网格中点，σ = 网格长度 × 固定 5 档之一）；
  2. 归一化到 `Σp_k = λ_g`；
  3. 固定 5 个 σ 比例：`1/12, 1/8, 1/6, 1/4, 1/2`，等权；
  4. 按 `λ_max = Σw / max(w)` 过滤：`λ_g ≤ λ_max` 的 σ 才能进轮盘；一个都不剩则配置无效；
  5. 60% 保持正态顺序，40% 打乱概率顺序（多重集和 λ 不变）。
- 每个采样点：`U ∈ [0,1)`，`U < p_k` 起一轮自动触发；每点最多一次。
- running（任何轮次）期间不抽，错过的点作废，不补；结束后从当前点继续。
- 外部事件不消耗网格，但事件轮占用的 running 时间会让自动点作废。
- 自动轮的 anchor `trigger=auto`，`trigger_detail` 记录网格、σ、模式、λ、p。

## 配置校验

- 网格/采样必须在固定选项内，且网格是采样的整数倍。
- 三个期望必须 ≤ 当前网格/采样/σ 集合下的 `λ_max`；否则配置端拒绝保存。
- 每天名义期望 `E_day = Σλ_g` 只是输出，实际 ≤ 名义（running 作废点）。

## UI

- 网格大小、采样间隔：分段选择。
- 三个期望：普通/低热/高热三个数字输入。
- 热/低时段：手写 `HH:MM-HH:MM;...`，分号分隔。
- 24h SVG 时间尺：按网格渲染热/冷/普通颜色、整点刻度、当前时间线。
- 显示每格上限、全天期望、全天物理上限；非法配置直接报错。

## 测试

`clock.test.mjs` 覆盖网格/期望/σ 过滤/打乱/事件优先级/sleep/schedule/跨日；`runtime.test.mjs` 覆盖自动轮锚点、L0 首轮、running 点作废、外发来源。
